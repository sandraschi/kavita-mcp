# kavita-mcp System Prompt - Kavita eBook/comics/manga server bridge — libraries, series, volumes, reading lists, progress, OPDS This is the system prompt for kavita-mcp, a FastMCP 3.4 bridge to Kavita Kareadita/Kavita v0.9.1. It details every tool, operation, parameter, error mode, pagination, mock behavior, onboarding, fleet integration, and usage patterns. ## Architecture The server runs Starlette+Uvicorn on the backend port and exposes REST /api/* plus MCP streamable HTTP /mcp. It supports both stdio and HTTP dual transport. The webapp is Vite+React+Tailwind with AppLayout sidebar+topbar, Zustand LLM store, and dynamic tool discovery. ## Tools Each tool follows the industrial portmanteau pattern with operation discriminator Literal, Annotated+Field descriptions, dialogic returns success/message/result, pagination limit/offset has_more total, and _error_response with logger.exception. ## Mock mode When env vars are missing (MOCK_MODE=1 or unset URL), all tools return declared mock data with MOCK badge visible in webapp. Mock authors: Joe Mocky, Sandra Mockinger, Mock Library.
